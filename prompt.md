## TECHNICAL SPECIFICATIONS

### Color Palette (Minimal Apple/Vercel Style):
- **Primary**: Pure Black (#000000)
- **Secondary**: Pure White (#ffffff)
- **Accent**: Neutral Gray (#6b7280)
- **Border**: Light Gray (#e5e7eb)
- **Text Primary**: Black (#000000)
- **Text Secondary**: Gray (#6b7280)

### Typography (Apple/Vercel Style):
- **Headlines**: -apple-system, BlinkMacSystemFont, Inter (Medium/Semibold)
- **Body**: -apple-system, BlinkMacSystemFont, Inter (Regular)
- **Code/Numbers**: SF Mono, Menlo, Monaco (Monospace)

### Design Principles:
- **Extreme minimalism** - remove everything non-essential
- **Generous whitespace** - let content breathe
- **System fonts** - native platform fonts only
- **No gradients or shadows** - flat design
- **Subtle hover states** - slight gray background changes
- **No animations** - instant state changes only

### Mobile Optimization:
- **Mobile-first design** with system font scaling
- **Touch targets** minimum 44px
- **Single column** layout on mobile
- **No horizontal scrolling**

### SEO Elements:
- **Title**: "Muhammad Ilzam Mulkhaq - Fullstack Developer | 30-Day MVP Development"
- **Meta Description**: "Turn your idea into MVP in 30 days. Expert fullstack developer with 6+ years experience. AI-powered development + proven boilerplates. Book free consultation."
- **Keywords**: fullstack developer, MVP development, React Laravel Flutter, Indonesia developer, startup development

### Performance:
- Lazy loading for images
- Optimized images (WebP format)
- Minimal third-party scripts
- Fast loading time (<3 seconds)

### Conversion Tracking:
- Google Analytics events for CTA clicks
- Heat mapping for user behavior
- A/B testing capability for headlines
- Contact form conversion tracking

### Images Needed:
1. Professional headshot (hero section)
2. Casual speaking/teaching photos (2-3)
3. Work environment/setup photos
4. Project screenshots (3 case studies)
5. Team collaboration photos
6. Tech setup/workspace photos

This structure follows proven conversion psychology principles while showcasing your technical expertise and unique positioning as an AI-powered MVP partner. Each section is designed to move prospects closer to booking a consultation call.
